# Product Context: Console Age Display

## Why This Project Exists
This project serves as a practical exercise for updating and practicing modern HTML5 and CSS skills. It provides a simple, focused use case that demonstrates key web development concepts without overwhelming complexity.

## Problems It Solves
1. **Skill Development**: Hands-on practice with modern HTML5 and CSS techniques
2. **Information Display**: Quick reference for gaming console release dates and current ages
3. **Learning Foundation**: Establishes a clean codebase for future TypeScript learning

## How It Should Work
### User Experience Flow
1. User navigates to the web page
2. Page loads with an attractive header and loading indicator
3. Console data fetches from JSON file
4. Table displays showing:
   - Console name and manufacturer
   - Release date (formatted as MMM YYYY)
   - Current age in years and months
5. Consoles sorted chronologically from oldest to newest
6. Clean, professional styling with responsive design

### Key Features
- **Dynamic Age Calculation**: Always shows current age relative to today's date
- **Clean Data Display**: Well-organized table format with clear typography
- **Visual Hierarchy**: Color-coded ages (vintage/retro/modern)
- **Responsive Design**: Works on desktop and mobile devices
- **Error Handling**: Graceful fallback if data fails to load

## User Experience Goals
- **Simplicity**: Clean, uncluttered interface focused on the data
- **Clarity**: Easy to scan and find information quickly
- **Professional**: Modern styling that demonstrates current web standards
- **Reliability**: Consistent performance across different browsers and devices

## Success Metrics
- Page loads within 2 seconds
- Data displays accurately for all consoles
- Responsive design works on mobile and desktop
- No console errors during normal usage
