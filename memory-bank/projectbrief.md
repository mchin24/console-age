# Project Brief: Console Age Display

## Core Requirements
Build a simple web page that displays the ages of various video game consoles based on their original release dates.

## Technical Stack
- **Primary**: Modern HTML5 and CSS
- **Future**: TypeScript for additional functionality
- **Data Source**: JSON file containing console information
- **Deployment**: Docker with nginx server

## Project Goals
1. Create a clean, modern HTML5 page
2. Display console ages dynamically calculated from current date
3. Load data from JSON file
4. Focus on updating HTML5 and CSS skills
5. Prepare foundation for future TypeScript enhancements

## Key Constraints
- Simple page focused on functionality over visual design initially
- Modern web standards (HTML5, CSS3)
- Responsive design principles
- Docker-based deployment

## Success Criteria
- Page loads and displays all console data correctly
- Ages calculate accurately in years and months
- Clean, readable code structure
- Working Docker deployment
- Proper development environment setup
